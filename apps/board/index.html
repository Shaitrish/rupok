FAQ

Questions teachers ask

Is Rupok really free?

Yes. The whole app is free and open source, with every feature, on every device. Rupok Cloud, a hosted add-on for sync, sharing and live classes, is coming with a free plan for every teacher.

Does it work with my smartboard or interactive panel?

Yes, with any brand: SMART, Promethean, BenQ, ViewSonic, Prestigio and others. Rupok runs in Chrome or Edge on the computer connected to the board, and uses its touch and pen like any browser app.

Do I need to install anything?

No. Open rupok.app/board in Chrome or Edge. You can install it from the browser menu so it opens in its own window. A desktop app for Windows and Linux is coming soon.

How does the AI part work?

Ask the AI you already use for a simulation, 3D model or quiz as a single HTML file, and paste it onto the board. Claude Code, Codex and OpenCode can build whole lessons through Rupok’s MCP server. More about the AI whiteboard.

How do students open my lessons?

Save the lesson as a .rpk file and send it on WhatsApp, Gmail or Google Drive. Students open it at rupok.app/open on a phone or computer, with no account, and replay the class.

Is Rupok open source?

Yes. The app is AGPL-3.0, and the .rpk file format, the Smart Object SDK and the AI skills are Apache-2.0. The code is on GitHub.

Does Rupok support Bangla?

Bangla text and fonts work in lessons today, and a Bangla interface is coming. বাংলায় পড়ুন.

How is Rupok different from SMART Notebook, OpenBoard or Note3?

Rupok is free with every feature on any board, runs in the browser, and adds AI-made Smart Objects and class replay. Those apps are stronger in other ways, such as mature desktop tools and content libraries. See the honest comparison.
