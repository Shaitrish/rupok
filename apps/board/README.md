# Rupok board (web app)

The board UI: SolidJS + TypeScript on top of the Rust engine (`crates/rupok-wasm`)
compiled to WebAssembly. The same app runs in a browser, in the Tauri desktop
shell (planned, `apps/desktop`) and as the student web viewer.

## Run

```sh
# one-time: Rust (rustup), bun or node, and the wasm-bindgen CLI
cargo install wasm-bindgen-cli --version 0.2.130 --locked

./scripts/dev.sh          # from the repo root → http://127.0.0.1:3737
```

## Layout

| Path | What |
|---|---|
| `src/controller.ts` | Engine glue: render loop, pointer input, files, autosave, presenter keys |
| `src/objects.ts` | Smart Object host: sandboxed iframes, CSP, SDK injection, bridge protocol |
| `src/pdf.ts` | PDF import (pdf.js): each page becomes a slide |
| `src/components/` | UI (see `DESIGN.md` at the repo root for the design system) |
| `src/icons.generated.ts` | Solar icon subset — regenerate with `node scripts/gen-icons.mjs` |
| `src/wasm/` | Generated by `wasm-bindgen` (git-ignored) |
