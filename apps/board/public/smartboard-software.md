# Free smartboard software that works on any board

> Rupok is free, open-source smartboard software for any interactive panel, smart board or projector. Write on PDF slides, add AI-made activities, replay every class. No licence.

Canonical: https://rupok.app/smartboard-software/ · Language: en · Updated: 2026-11-23

Rupok turns any interactive flat panel, smart board or projector into a teaching board: fast pen ink on your slides, live interactive lessons, and a replay of every class. Free and open source, with no licence keys and no account.

## Interactive whiteboard software, minus the licence

Most smartboard software is free only on its maker’s own hardware, or keeps the best features for a paid edition. Rupok gives every feature to every board.

- **Any brand**: SMART, Promethean, BenQ, ViewSonic, Prestigio or no-name panels, projectors with a pen, laptops and tablets.
- **Every feature free**: No “Plus” or “Professional” edition. Recording, PDF and AI aren’t locked away.
- **Nothing to install**: Open rupok.app/board in Chrome, Edge or Safari. Works on Windows, macOS, Linux and ChromeOS.

## Everything a smartboard lesson needs

### Write

- GPU ink that draws a stroke in about a millisecond and stays smooth with 100,000 strokes.
- Pressure, palm rejection, highlighter, shapes, laser pointer, eraser and lasso.
- Big, touch-friendly toolbar for an 86-inch panel; keyboard shortcuts on a laptop.

### Present

- Import a PDF and write on every page. (Using PowerPoint? Save it as PDF first.)
- Teach mode keeps the slide fitted to the screen with minimal chrome.
- Step through slides and live objects with a presentation clicker.

### Bring lessons to life

- Smart Objects: live simulations, 3D models and quizzes on the slide. Your AI makes them ([see how](https://rupok.app/ai-whiteboard/)).
- Write on top of a running simulation with the pen.

### Keep the class

- Every stroke is saved with its timing: replay any page at 1–8×.
- Save the lesson as one `.rpk` file and share it; students open it at [rupok.app/open](https://rupok.app/open/).
- Download the lesson as a PDF for printing.

## Open-source smartboard software, so it stays free

Rupok’s code is open source under the AGPL-3.0, and its `.rpk` lesson format is published under Apache-2.0. Nobody can take the free version away, put features behind a paywall, or lock your lessons into one company’s app. A school can run it on every device forever.

Rupok is made by Shaitrish in Bangladesh, and built in the open on [GitHub](https://github.com/Shaitrish/rupok) with a public roadmap.

## Set it up on your board in two minutes

1. **Open Chrome, Edge or Safari on the board’s computer.** The built-in PC (OPS module) of an interactive flat panel, or the laptop connected to your projector.
2. **Go to rupok.app/board.** Pin it to the taskbar or install it from the browser’s menu so it opens like an app.
3. **Drop in your slides.** Drag a PDF onto the board; every page becomes a slide.
4. **Teach.** Switch to Teach mode, pick up the pen, and press the clicker to move on.

*Panels running only their built-in Android system vary: Rupok needs a browser with WebGPU or WebGL2. A connected Windows, Linux or ChromeOS computer is the safe choice.*

## Questions people ask

### What is the best smartboard software for teachers?

If your school is invested in one brand, its own software (SMART Notebook, ActivInspire) fits that hardware best. If you have mixed boards, want every feature free, or want AI-made interactive lessons and class replay, Rupok is built for that. See the [comparison](https://rupok.app/compare/).

### Is Rupok really free?

Yes. The whole app is free and open source, with no paid edition of the software. A hosted add-on, Rupok Cloud (sync, share links and live classes), is coming with a free plan for every teacher.

### Do I need to download smartboard software for my PC?

No download is needed: Rupok runs in Chrome, Edge or Safari. You can install it from the browser menu so it opens in its own window. There is also a desktop app for Windows, Mac and Linux: see [Download](https://rupok.app/download/).

### Does it work with SMART, Promethean, BenQ, ViewSonic or Prestigio boards?

Yes. Rupok runs on the computer connected to the board and uses its touch and pen like any browser app, so the brand doesn’t matter.

### Does Rupok work offline?

Once the board is open, it runs on your device: drawing, slides and replay don’t need the internet. An offline install (PWA) is coming soon.

### Can I use my PowerPoint slides?

Save the presentation as a PDF (File → Save As → PDF in PowerPoint), then drop the PDF onto the board. Every slide becomes a page you can write on.

### Does Rupok support Bangla?

Yes, for lesson content: Bangla text and fonts work today. A Bangla interface is coming. [বাংলায় পড়ুন](https://rupok.app/bn/).
