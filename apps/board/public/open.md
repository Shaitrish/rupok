# Open .rpk files: free online RPK viewer

Got a lesson file from your teacher on WhatsApp, Gmail or Google Drive? Drop it here. It opens right in your browser, with the class replay and the live activities still working.

## What is an .rpk file?

An **RPK (Rich Presentation Kit) file is a Rupok lesson.** Rupok is a free, open-source whiteboard for teachers, and a `.rpk` file holds one whole class in a single file:

- **Slides:** every page the teacher prepared, including PDF slides.
- **Ink:** everything written on them with the pen.
- **Live Smart Objects:** simulations, 3D models and quizzes that still work.
- **A replay:** the timing of every stroke, so you can watch the class unfold.

- **File type**: Rupok lesson (RPK: Rich Presentation Kit)
- **Extension**: `.rpk`
- **Media type**: `application/vnd.rupok.lesson+zip`
- **Inside**: A ZIP package: the lesson document with its full history, images and Smart Objects
- **Opens with**: Rupok, free in Chrome, Edge or Safari, on this page or at rupok.app/board
- **Format**: Open and documented ([RPK file format](https://rupok.app/rpk/), Apache-2.0 [spec](https://github.com/Shaitrish/rupok/blob/main/spec/rupok-format.md))
- **Readable by AI**: Yes: each file carries a Markdown outline ChatGPT or Claude can read

## How to open an .rpk file on a phone or computer

### On a phone (Android or iPhone)

1. **Save the file.** In WhatsApp, tap the file and download it (on iPhone: Share → Save to Files). In Gmail, tap the attachment’s download icon. In Google Drive, tap ⋮ → Download.
2. **Open rupok.app/open** in your phone’s browser. Chrome works best.
3. **Tap “Choose a .rpk file”** and pick it from Downloads or Files. The lesson opens in Student mode.

### On a computer

1. **Download the file** from WhatsApp Web, Gmail or Google Drive.
2. **Drag it onto this page,** or click “Choose a .rpk file”. Use Chrome, Edge or Safari.
3. **Replay the class.** Press play, flip through the pages and try the live objects.

*Student mode is read-only: you can’t change your teacher’s lesson by accident.*

## What you can do with the lesson

The lesson opens exactly as your teacher left it. Press play to watch it being written, stroke by stroke, at 1–8× speed. Pause on a diagram, zoom in, and use the simulations and quizzes yourself.

- **Replay at 1–8×**: Watch every stroke appear in order.
- **Try the objects**: Simulations and quizzes still work.
- **Zoom and page through**: Every slide, sharp at any size.

## How to turn an .rpk file into a PDF

1. **Open the .rpk file here.** Drop it in the box at the top of this page.
2. **Press Download PDF.** You get every page with the teacher’s ink on it.
3. **Print it or keep it.** Good for revision, printing, or reading where there’s no internet.

*The PDF is made in your browser. Nothing is uploaded.*

## Questions people ask

### What is an .rpk file?

An .rpk file is a lesson made with Rupok, a free whiteboard for teachers. It holds the slides, the teacher’s ink, live interactive Smart Objects and a replay of the class. Technically it’s a ZIP package with an open, documented format: see [the RPK file format](https://rupok.app/rpk/).

### What does RPK stand for?

RPK stands for Rich Presentation Kit, the name of Rupok’s lesson file format.

### How do I open an .rpk file?

Drop it on this page, or tap “Choose a .rpk file”. It opens in your browser in Rupok’s Student mode. You don’t need an account or an app.

### Can I open an .rpk file on my phone?

Yes. Save the file from WhatsApp, Gmail or Google Drive, open rupok.app/open in your phone’s browser (Chrome works best), and choose the file.

### How do I convert an .rpk file to PDF?

Open the file on this page, then press Download PDF in the viewer. The PDF has every page with the teacher’s ink, and it’s made on your device.

### Can ChatGPT or Claude read my .rpk file?

Yes. Upload the file and ask about the lesson: every .rpk from current Rupok versions includes a plain Markdown outline of its pages (`content.md`) that AI models read. See [how AI reads RPK files](https://rupok.app/rpk/#ai).

### Is my file uploaded anywhere?

No. The file is opened by your browser on your device. This page hands it to the viewer through your browser’s local storage, and nothing is sent to a server.

### Can I change the lesson?

Student mode is read-only, so you can replay the class and use the live objects without changing anything. Teachers edit lessons at [rupok.app/board](https://rupok.app/board/).

### My .rpk file won’t open. What can I do?

First download it again: a half-finished download is the most common cause. Make sure the name ends in `.rpk` (some apps add `.zip` or a number; that’s fine, this page checks the file itself).

Other programs also use the .rpk extension, for example Esri CityEngine rule packages, Tizen resource packages and TI-99/4A cartridge files for the MAME emulator. Those aren’t Rupok lessons; open them with the program that made them.

### How do I make my own .rpk lessons?

Open [rupok.app/board](https://rupok.app/board/), the free whiteboard for teachers. Write on slides, add live AI-made activities, and save the lesson as a .rpk file to share.
